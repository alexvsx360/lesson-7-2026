# JavaScript למתחילים — שיעור 7 · מצגת אינטראקטיבית

מצגת אינטראקטיבית ל**שיעור 7** בקורס JavaScript למתחילים (PrimeTech 2026).  
בונה על שיעורים 5–6 ומתמקדת ב-**Scope**, **Validation**, **Loops**, שיטות **מערכים ואובייקטים**, **Iteration**, מבנים מקוננים ו-**Spread Operator**.

## מטרת השיעור

לעבוד עם נתונים אמיתיים בצורה בטוחה ונקייה:
- להבין איפה משתנים «חיים» (Scope)
- לאמת קלט מהמשתמש (Validation)
- לחזור על פעולות עם לולאות
- לנהל מערכים ואובייקטים עם המתודות הנפוצות ביותר
